features:
  - title: Inertia
    details: When the body moves, turns or lands, the flesh lags behind, jiggles and returns to place. Each part gets its own size and rhythm, and parts that should move less are set by painting.
  - title: Contact
    details: Where a hand or an object presses, the flesh dents, and a wide push moves the flesh lump attached to a bone aside as a whole. With Contact Detail set to Full, the flesh around the dent rises and a sliding hand drags the skin along.
  - title: Real-time performance
    details: Contact is computed on the GPU only while something touches the mesh or a dent is recovering. Meshes that are small on screen or off screen pause, and crowds can keep only the jiggle.
  - title: Production-ready
    details: Install from a git URL in the Package Manager, bake once in the editor and add a single component. It works on both skinned and static meshes, and the bake also creates the Softbody/Lit material.
